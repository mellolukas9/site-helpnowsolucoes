Separe os acessos

Antes de tudo
01

Google Workspace

admin.google.com · calendar.google.com

1.1 Anote os registros de e-mail atuais

Em admin.google.com → Conta → Domínios → Gerenciar domínios, confira se helpnowsolucoes.com.br está como Verificado e com o Gmail ativo. Guarde o TXT de verificação do Google (google-site-verification=…): ele precisa existir no DNS para sempre.

1.2 Gere a assinatura DKIM

  1. Apps → Google Workspace → Gmail → Autenticar e-mail.
  2. Selecione o domínio, clique em Gerar novo registro (2048 bits, prefixo google).
  3. Copie o valor do TXT gerado. Ele entra no DNS na etapa 02. Volte aqui depois e clique em Iniciar autenticação.

1.3 Libere o Web App do Apps Script para o público

O agendamento precisa ser publicado com acesso "Qualquer pessoa". Essa opção só aparece se o compartilhamento externo estiver liberado.

  1. Apps → Google Workspace → Drive e Documentos → Configurações de compartilhamento → Opções de compartilhamento.
  2. Em "Compartilhamento fora de HelpNow", marque Ativado e salve. Pode levar alguns minutos para valer.

1.4 Prepare a agenda do comercial@

  1. Logado como comercial@, abra calendar.google.com → Configurações → Geral: fuso horário (GMT-03:00) Horário de Brasília.
  2. Outras agendas → + → Procurar agendas de interesse → Feriados regionais → Brasil. O script usa essa agenda para bloquear feriados (e tem uma lista de reserva no código).
  3. Opcional: em Horário de trabalho, marque seg–sex, 9h–12h e 14h–18h. Não é obrigatório: as regras de horário estão no script.
Regra prática

Qualquer compromisso marcado como "Ocupado" na agenda do comercial@ some automaticamente do site. Para bloquear um dia, basta criar um evento de dia inteiro como "Ocupado".

02

DNS do domínio

registro.br → seu domínio

2.1 Descubra quem responde pelo DNS hoje

No Registro.br, abra o domínio e veja a seção DNS.

  • Se aparecem servidores da HostGator (algo como nsXXX.hostgator.com.br): a zona é editada no cPanel. Vá para a etapa 03.2.
  • Se aparece "Utilizando os servidores DNS do Registro.br": a zona é editada no próprio Registro.br, em Configurar zona DNS / Editar zona. Use a tabela abaixo ali.
Recomendação

Apontar o domínio para os DNS da HostGator deixa tudo num lugar só (cPanel). Os nameservers corretos estão no Portal do Cliente HostGator / e-mail de boas-vindas do plano. Antes de trocar, crie na zona da HostGator os registros de e-mail da tabela abaixo; só então altere os servidores no Registro.br (Alterar servidores DNS).

2.2 Registros que a zona precisa ter

TipoNomeValorPrioridade / obs.
A@IP do servidor HostGator (cPanel → barra lateral "Endereço IP compartilhado")Site
CNAMEwwwhelpnowsolucoes.com.brSite (o .htaccess redireciona www → sem www)
MX@smtp.google.comPrioridade 1 · apague qualquer outro MX (ex.: mail.helpnowsolucoes.com.br)

Conferir a propagação (terminal)
dig +short A helpnowsolucoes.com.br
dig +short MX helpnowsolucoes.com.br
dig +short TXT helpnowsolucoes.com.br
dig +short TXT google._domainkey.helpnowsolucoes.com.br

Sem terminal? Use um verificador de DNS online (ex.: dnschecker.org) com os mesmos nomes.

03

HostGator

Portal do Cliente · cPanel

3.1 Domínio principal do plano

O Plano P hospeda um domínio. Confirme no Portal do Cliente que o plano está associado a helpnowsolucoes.com.br como domínio principal e que o site vai em public_html/.

3.2 Zona DNS (se o DNS estiver na HostGator)

cPanel → Domínios → Zone Editor → Gerenciar. Crie/ajuste os registros da tabela 2.2 e remova MX antigos que apontem para a própria HostGator.

3.3 E-mail fica no Google

cPanel → E-mail → Roteamento de e-mail (Email Routing): selecione Trocador de e-mail remoto (Remote Mail Exchanger). Sem isso, mensagens enviadas pelo próprio servidor (como formulários) podem ficar presas na HostGator. Não crie contas de e-mail no cPanel.

3.4 PHP e SSL

  1. cPanel → Software → MultiPHP Manager (ou "Selecionar versão do PHP"): defina PHP 8.2 ou superior para o domínio e confirme que a extensão curl está ativa.
  2. SSL gratuito: no Portal do Cliente ou em cPanel → Segurança → SSL/TLS Status, confirme o certificado para helpnowsolucoes.com.br e www. Ele só é emitido depois que o DNS apontar para a HostGator.
  3. Anote o diretório inicial (barra lateral do cPanel, algo como /home/usuario). O arquivo de configuração secreto vai nele, fora do public_html.
04

Planilha e Apps Script

Logado como comercial@ · drive.google.com

4.1 Criar a planilha

  1. No Drive do comercial@, crie uma planilha chamada HelpNow — Leads.
  2. Menu Extensões → Apps Script. Renomeie o projeto para HelpNow Agendamento.

4.2 Colar o código

  1. Substitua o conteúdo de Código.gs pelo apps-script/Code.gs do projeto.
  2. Configurações do projeto (engrenagem) → marque "Mostrar arquivo de manifesto appsscript.json" → cole o apps-script/appsscript.json.
  3. No editor, Serviços (+) → Google Calendar API → Adicionar. É o que cria o link do Meet.

4.3 Rodar o setup e autorizar

  1. Selecione a função setup e clique em Executar.
  2. Autorize com a conta comercial@ (agenda, planilha, envio de e-mail, gatilhos). Se aparecer "app não verificado", clique em Avançado → Acessar HelpNow Agendamento: é o seu próprio script.
  3. O setup cria a aba Leads com cabeçalhos, o gatilho de lembrete (a cada hora) e gera o SHARED_SECRET. Copie o secret do Registro de execução (ou de Configurações → Propriedades do script).
  4. Rode testSlots e confira no registro se aparecem horários a partir de 15/10 (seg–sex; 9, 10, 11, 14, 15, 16 e 17h).

4.4 Publicar como Web App

  1. Implantar → Nova implantação → tipo "App da Web".
  2. Descrição "v1" · Executar como: Eu (comercial@) · Quem pode acessar: Qualquer pessoa.
  3. Copie a URL do app da Web (termina em /exec).
Ao atualizar o código

Use Implantar → Gerenciar implantações → editar (lápis) → Versão: Nova versão. Assim a URL continua a mesma. Uma "Nova implantação" gera outra URL e o site para de funcionar até você trocar no arquivo de configuração.

05

Publicar o site

Seu computador → cPanel

5.1 Testar no seu computador (opcional)

Na pasta helpnow-site
php -S localhost:8000 -t public_html tools/dev-router.php
# http://localhost:8000/agendamento  → agenda em modo simulado

O site não tem etapa de build: a pasta public_html/ do projeto já é exatamente o que vai para o servidor.

5.2 Enviar para a HostGator

  1. Faça backup e esvazie o public_html/ do servidor (se houver página padrão da HostGator).
  2. Compacte o conteúdo da pasta public_html/ do projeto em um .zip, envie pelo Gerenciador de Arquivos para o public_html do servidor e use "Extrair". FTP também serve.
Arquivos ocultos

O .htaccess começa com ponto. No Gerenciador de Arquivos, ative Configurações → Mostrar arquivos ocultos para conferir que ele foi enviado.

5.3 Arquivo de configuração secreto

Copie server-config/helpnow-config.sample.php para o diretório inicial (fora do public_html) com o nome helpnow-config.php e preencha:

/home/usuario/helpnow-config.php
<?php
return [
  'APPS_SCRIPT_URL' => 'https://script.google.com/macros/s/XXXXXXXX/exec',
  'SHARED_SECRET'   => 'cole-aqui-o-secret-do-setup',
  'ALLOWED_ORIGINS' => ['https://helpnowsolucoes.com.br', 'https://www.helpnowsolucoes.com.br'],
  'MOCK'            => false,
];

5.4 Teste rápido da API

Abra no navegador, nesta ordem
https://helpnowsolucoes.com.br/api/agenda.php?action=health
https://helpnowsolucoes.com.br/api/agenda.php?action=slots&from=2026-10-15&to=2026-10-23

O primeiro deve mostrar "mode":"live" (se mostrar "mock", o arquivo de configuração não foi encontrado). O segundo deve voltar um JSON com "days" e horários. Se der erro, veja Se algo der errado; o log técnico fica em /home/usuario/helpnow-agenda.log.

07

WhatsApp Business

App no celular · Ferramentas comerciais
  1. Configurações → Ferramentas comerciais → Mensagem de saudação → ativar.
  2. Cole a mensagem abaixo. Destinatários: Todos.
  3. A saudação é enviada quando a pessoa fala com o número pela primeira vez ou após 14 dias sem conversa. Teste de outro celular que nunca falou com o número.
Mensagem de saudação
Olá! Que bom te ver por aqui. Aqui é a HelpNow, consultoria e gestão de negócios para TOTVS RM e Protheus.

Garanta seus 60 minutos com um especialista para investigar um problema real do seu backoffice. Escolha o melhor dia e horário:

https://helpnowsolucoes.com.br/agendamento?origem=universo-totvs

Se preferir, é só responder aqui que um especialista fala com você. Juntos vamos mais longe!
Depois do evento

Troque o final do link para ?origem=instagram ou remova o parâmetro, para a planilha separar quem veio do Universo TOTVS.

B

Plano B para terça

Só se o site não estiver no ar a tempo

A Google Agenda tem uma página de agendamento pronta (o Business Starter permite uma). Ela não tem o visual da HelpNow nem grava na planilha, mas mostra os horários livres e cria o Meet.

  1. Logado como comercial@, em calendar.google.com: Criar → Agendamento de horários.
  2. Título "Diagnóstico HelpNow — 60 min", duração 1h, seg–sex 9h–12h e 14h–18h, início em 15/10, videoconferência Google Meet.
  3. No formulário de reserva, adicione as perguntas: Empresa, WhatsApp, ERP utilizado, Problema a investigar.
  4. Salve, copie o link da página e use na saudação do WhatsApp até o site ficar pronto.
